观测条带反推参数

复用上方 DNA 序列、拓扑与全部 1～8 条酶规则（按完全酶切处理，忽略单点切开概率）。 枚举包括空酶组合在内的全部酶组合，预测片段长度按多重集与观测配对。
配对规则：每条观测须与一条不同的预测片段配对且绝对差 ≤ 容差； 未配对预测片段数 ≤ 允许漏检数；不允许出现多余观测。

目标片段分离设计参数

复用上方 DNA 序列、拓扑与全部 1～8 条酶规则（按完全酶切处理，忽略单点切开概率）。 枚举全部非空酶组合，只保留切后存在恰好覆盖目标区间的片段、 且目标片段长度与每条其他片段长度之差的绝对值均 ≥ 最小条带间距的组合。
线性：0 ≤ 起点 < 终点 ≤ 序列长度，且区间须短于全长；序列两端为天然边界， 目标端点落在 0 或全长处时无需实际切点。环状：起点、终点均在 [0, 长度) 且不相等， 起点 > 终点表示跨原点，目标两端均须形成实际切点。 结果按 酶数升序 → 最小实际间距降序 → 酶 ID 字典序 排列。 预置示例可试：切换到环状拓扑，目标区间 [24, 6)（跨原点）、间距 3 bp，可得到可行组合。

平切片段拼接参数

复用上方 DNA 序列、拓扑与全部 1～8 条酶规则做完全酶切（忽略单点切开概率）， 片段编号沿用完全酶切结果；未切开的环状分子不可作为原料，片段数超过 16 条时拒绝计算。 从所得片段中选取若干条（每个编号最多用一次，同序列不同编号分别计库存），每条可按 + 原序列或− 反向互补使用，只允许完整片段首尾直连， 拼接结果须与目标逐位相等。求片段数最少的方案；并列时依次比较路径中的 （数字编号、方向），编号小者优先，同编号 + 先于 −（子集动态规划合并等价状态，不枚举全部排列）。

环状双酶图谱重建

只依据实验长度，不需要 DNA 序列或酶识别串：假定同一环状分子被完全切开、 A、B 切点互不重合，输入 A、B 各自单酶切及 A+B 双酶切的片段长度多重集（重复长度按出现次数计）。 枚举双酶片段的环上次序与边界的 A/B 归属，只保留能同时重现两组单酶长度多重集的图谱； 旋转与镜像视为同一图谱，每类取（切点标签, 其后间距）序列字典序最小的表示并据此从 0 计坐标。
前提：各长度为正整数；三组总长相等且为 4～5000 bp；双酶切片段数 = A、B 单酶切片段数之和。 违反前提返回 HTTP 400；前提满足但无图谱能重现两组单酶长度时明确说明无解。

未知酶规则反推

录入 1～3 份 DNA 样本（各 6～300 bp、仅 A/C/G/T，空白自动忽略）， 每份给定拓扑与实测的 0 基切点边界（线性 0～序列长度，环状 0～长度−1，同一样本内不得重复； 全部样本合计至少一个切点，单份可为空）。假定同一虚拟平切酶在所有样本上 完全切开：识别串只含 A/C/G/T、长 3～6 位，切割偏移 0～串长；沿用双向查找、允许重叠、环状跨界匹配与同一边界合并规则。 找出使每份样本的预测切点集合与实测严格相等的全部规则； （识别串, 偏移）与（反向互补串, 串长−偏移）视为同一规则，取字典序较小的表示， 结果按（串长, 识别串, 偏移）排序。
候选规则由实测切点最少的非空样本枚举（覆盖切点的 3～6 位窗口正/反两方向），再逐条在全部样本上验证。

样本鉴别酶组合

录入 2～5 份 DNA 样本（各 4～5000 bp、仅 A/C/G/T，空白自动忽略）， 每份各自选择线性或环状；共用上方 1～8 条酶规则（现有格式，按完全酶切处理， 忽略单点切开概率；识别串不得长于任一样本），并输入 0～10 bp 条带容差。 枚举全部非空酶组合，对每份样本按双向查找、允许重叠、环状跨界匹配与同一边界合并规则 完全酶切；片段长度保留重复并升序排列。两份样本若片段数相同且对应长度差均不超过容差， 则视为不可区分，否则可区分。只返回能使所有样本两两可区分且 用酶数最少的全部组合（按酶 ID 字典序排列）。
各酶在各样本上的切点只扫描一次，组合的切点为各酶边界之并，不会对每种组合重新扫描序列。

酶活性校准

复用上方 DNA 序列（校准限 6～300 bp）、拓扑与 1～3 条酶规则 （忽略酶规则上填写的单点切开概率，概率由本功能枚举）。各酶单点切开概率从 0、0.1、…、1 共 11 个取值枚举，按部分酶切模型计算预测丰度 （同一边界同酶命中去重、不同酶独立切开；线性仅有普通片段，环状另有未切开全环与 单切点全长线性片段）。录入 1～40 条互异的（片段长度, 类型, 观测丰度）与 0～0.1 绝对容差，仅核对录入的行（未预测到的行按 0 计）， 返回各行误差均不超过容差的全部概率组合；预测的不同切点边界超过 30 个时拒绝。
